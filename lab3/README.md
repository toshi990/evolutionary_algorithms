# Лабораторная работа №3. Вариант 14, трек A

Выбор оборудования для экспедиции по полезности, массе и надёжности.
[Отчёт](REPORT.md).

## Запуск

Для расчётов достаточно стандартной библиотеки Python.
Команды выполняются из папки `lab3`.

```bash
python3 main.py demo --seed 100
python3 main.py experiment
python3 main.py view
python3 main.py check
```

`demo` выполняет по одному запуску NSGA-II и ГА со взвешенной суммой.
Выводятся показатели качества и четыре характерных комплекта.
Результаты сохраняются в `results/demo/`.

`experiment` выполняет по 20 запусков каждого метода с бюджетом 4200 оценок
на запуск. У взвешенной суммы этот бюджет делится между семью профилями весов.
Результаты сохраняются в `results/experiment/`, отчёт — в `REPORT.md`.
Повторная серия обновляет эти файлы.

`view` открывает страницу полной серии: таблицу, графики и состав комплектов.
`check` сверяет сохранённые решения, статистику и траектории с исходными данными.

Пример изменения seed и бюджета:

```bash
python3 main.py demo --seed 105 --budget 8400
```

## Данные и результаты

В `data/equipment.json` находятся 30 предметов: три альтернативы в каждой из
десяти категорий. Комплект содержит по одному предмету из каждой категории.
Надёжность считается произведением вероятностей исправности предметов
при предположении независимых отказов. Оценки полезности и надёжности синтетические.

Параметры алгоритмов, веса и seed серии заданы в `config.json`, код находится
в `algorithms/`. Команда `python3 generate_data.py` повторяет генерацию данных.
После изменения данных серия экспериментов выполняется заново.

В `results/experiment/`: `runs.csv` — итоги запусков, `summary.csv` — статистика,
`history.csv` — сходимость, `fronts.csv` — найденные решения,
`exact_front.csv` — точный фронт, `representatives.json` — характерные комплекты.
Рисунки сохраняются в SVG. При установленном Matplotlib создаются также PNG:

```bash
python3 -m pip install -r requirements-plots.txt
```
