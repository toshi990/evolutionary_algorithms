# Лабораторная работа №1. Вариант 14

Поиск минимума функции Стыблинского—Танга на `[-5, 5]^7` генетическим алгоритмом.
[Отчёт](REPORT.md).

## Запуск

Использована стандартная библиотека Python; дополнительные пакеты не нужны.
Команды выполняются из папки `lab1`.

```bash
python3 main.py single --seed 42
python3 main.py experiment
python3 main.py improved --seed 42
python3 compare_improved.py
```

`single` выполняет один запуск базового ГА, `improved` — ГА с гибридной мутацией.
Выводятся найденный вектор, значение функции, ошибка относительно известного
минимума и число вычислений.

`experiment` выполняет по 20 запусков ГА с масштабами мутации 0.2 и 0.8
и случайного поиска. `compare_improved.py` сравнивает базовую и гибридную мутации
на 20 запусках. Бюджет каждого запуска — 50 000 вычислений функции.

Пример изменения параметров:

```bash
python3 main.py experiment --runs 20 --population 100 --budget 50000 --sigma-a 0.2 --sigma-b 0.8
```

Результаты сохраняются в `results/`: `runs.csv` и `summary.csv` содержат итоги
основной серии, `generations_*.csv` и графики SVG — сходимость,
`improved_runs.csv` и `improved_summary.csv` — сравнение с гибридной мутацией.
Повторный запуск серии обновляет её результаты. Параметр `--output` задаёт другую
папку относительно текущего рабочего каталога.

## Визуализация

```bash
python3 main.py visualize
python3 visualize_improved.py
```

Открываются HTML-страницы из `visualizations/`. Их также можно открыть вручную.
Доступны отдельные шаги, переход к следующему поколению и анимация.
В демонстрации 30 особей; в экспериментах отчёта — 100. В браузере используется
отдельный генератор случайных чисел, поэтому траектория отличается от Python.
Вариант с Tkinter находится в `algorithms/visualizer.py`.
