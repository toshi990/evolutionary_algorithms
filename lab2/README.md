# Лабораторная работа №2. Вариант 14

Расстановка наблюдательных пунктов на графе при ограничении их числа.
[Отчёт](REPORT.md).

## Запуск

Использована стандартная библиотека Python; дополнительные пакеты не нужны.
Команды выполняются из папки `lab2`.

```bash
python3 main.py demo --seed 100
python3 main.py experiment
python3 main.py view
python3 main.py check
```

`demo` выполняет один запуск ГА с ремонтом и обменной мутацией. Программа выводит
выбранные вершины, покрытие и число вычислений. Результат сохраняется в
`results/demo/`.

`experiment` выполняет по 20 запусков трёх конфигураций ГА и случайного
допустимого поиска. Бюджет каждого запуска — 4000 вычислений покрытия.
Таблицы, хромосомы и графики сохраняются в `results/experiment/`, отчёт —
в `REPORT.md`. Повторная серия обновляет эти файлы.

`view` открывает страницу результатов основной серии; `check` проверяет сохранённые
решения, таблицы, траектории и соответствие исходному графу.

Пример запуска другого метода с изменённым бюджетом:

```bash
python3 main.py demo --seed 101 --method penalty_flip --budget 8000
```

Методы: `penalty_flip` — штраф и инверсия бита; `repair_flip` — ремонт и инверсия;
`repair_swap` — ремонт и обмен выбранной вершины со свободной.

## Данные и параметры

В `data/graph.json` сохранён граф из 36 вершин и 63 рёбер, лимит — 4 пункта.
Пункт покрывает свою вершину и её непосредственных соседей. Настройки ГА и seed
серии заданы в `config.json`. Алгоритмы находятся в `algorithms/`.

```bash
python3 generate_data.py
python3 main.py examples
```

Первая команда повторяет генерацию графа с seed из конфигурации, вторая показывает
примеры допустимых и недопустимых решений. После изменения входных данных
серия экспериментов выполняется заново.
